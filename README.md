# Стихии Бездны

Минималистичная 2D-метроидвания для телефона (Godot 4.7, рендер Mobile, альбомная ориентация).
Вся графика и звук генерируются кодом — внешних ассетов нет.

## Сюжет и прогрессия

Герой — дух стихий. В начале владеет **Огнём** и **Водой** и мгновенно переключается между ними.
Стражи подземелий хранят новые стихии и печати:

| Стихия | Где взять | Что открывает |
|---|---|---|
| Огонь | с начала | сжигает деревянные завалы и паутину, лава не вредит |
| Вода | с начала | гасит пламенные стены, позволяет плавать |
| Яд | Пылающий Страж (тронный зал замка) | разъедает решётки, отрава не вредит |
| Ветер | Королева Пауков (пещеры) | двойной прыжок, сильная отдача |
| Земля | Каменный Колосс (глубины) | крушит треснувший камень, шипы не вредят |

Элементный цикл урона: **Вода > Огонь > Яд > Земля > Ветер > Вода** (×2 по слабости, ×0.25 по своей стихии).

Мир — 32 комнаты: **замок** (с башней, погребом, темницей и криптой), **пещеры** (болото, грот,
шахта, паучье гнездо, утёс) и **ад**. Врата Ада открываются тремя печатями стражей.
Новые способности открывают проходы и тайники в уже пройденных местах (сундуки, сердца, короткие пути).

- 15 видов врагов: слизни, летучие мыши, скелеты-лучники, рыцари со щитом, бесы, пираньи, призраки,
  пауки, жабы, големы, кристальные турели, демоны, адские псы, огненные черепа, призраки-телепортёры.
- 3 мини-босса и финальный **Владыка Бездны**: аура меняет стихию, бить нужно стихией,
  которая её побеждает; три фазы, спирали снарядов, призыв слуг, лавовый пол в последней фазе.
- 3 торговца (сердца, флаконы, рывок, сила, амулет, магнит, карта) — монеты с врагов и из сундуков.
- Алтари: лечение, флаконы, сохранение и точка возрождения.

## Управление

Телефон: левая половина экрана — плавающий джойстик (вверх/вниз — прицел, удерживать вниз — спрыгнуть
с платформы), справа — прыжок, атака (удерживать), флакон, рывок, действие. Стихии — кнопки вверху справа.

Клавиатура: ←→/AD — бег, Пробел/Z — прыжок, X/J — атака, C/Shift — рывок, F — флакон,
E/↑ — действие, 1–5 или Q/R — стихии, M — карта, Esc — пауза.

## Структура

- `scripts/` — игра (`main.gd` — корень, `player.gd`, `level.gd`, `enemies/`, `bosses/`, `hud.gd`, `ui.gd`, `sfx.gd`)
- `data/world.json` — карта мира, генерируется `tools/build_world.py`
  (`python3 tools/build_world.py --check --preview map.png` — проверка проходимости для каждого набора стихий)
- `tests/` — автотесты: `godot --headless --fixed-fps 60 -s res://tests/play_test.gd` и `smoke_test.gd`

Для сборки под Android: Проект → Экспорт → Android (нужны шаблоны экспорта Godot 4.7).
